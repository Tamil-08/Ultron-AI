# 🤖 ULTRON — AI Voice Assistant

> A futuristic AI voice assistant built with **Python, LiveKit, Google Gemini Realtime AI, and ADB**.

![ULTRON Orb UI](assets/screenshot.png)

ULTRON is a voice-controlled AI assistant inspired by **Sagar Builds' ULTRON project**. I recreated the core concept and added a few extra features and improvements while learning and experimenting with real-time AI and automation.

## ✨ Features
* 🎙️ Real-time AI voice conversation
* 🧠 Google Gemini Realtime AI
* 🔊 Natural voice responses
* 🌐 Open websites on PC using voice commands
* 📱 Control Android apps using ADB
* 🎧 Audio enhancement & noise handling
* ⚡ Wake-word based interaction
* 🤖 Custom ULTRON personality
* 🛠️ Added extra commands and automation features

## 🛠️ Tech Stack
* **Python**
* **LiveKit Agents**
* **Google Gemini Realtime API**
* **ADB (Android Debug Bridge)**
* **Python-dotenv**

## 🚀 Setup

### Clone the repository
```bash
git clone https://github.com/Tamil-08/Ultron-voice-asign.git
cd Ultron-voice-asign
```

### Install dependencies
```bash
pip install -r requirements.txt
```

### Add environment variables
Create a `.env` file:
```env
GOOGLE_API_KEY=your_google_api_key
```

### Run
```bash
python agent.py
```

For Android control, make sure **ADB is installed** and your phone is connected:
```bash
adb devices
```
